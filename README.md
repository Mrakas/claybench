# ClayBench project page

Static project page for **ClayBench: Evaluating Text-to-Clay-to-Video Generation**.

Live at https://mrakas.github.io/claybench/

- `index.html` page, `cases.js` case data for the results gallery
- `media/hero` 720p clay/render pairs for the top comparison slider
- `media/cases`, `media/clayrep` 640p case videos
- `img` paper figures, first frames, model logos (sources in `img/logos/SOURCES.md`)

All videos are generated. No real footage is included.
